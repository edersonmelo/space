# Feature nova
1. Identificar o projeto (`agentes/contexto/indice.md`) e ler o `CLAUDE.md` dele.
2. Spec curta com o `especificador` (comportamento, critérios de aceite). Aprovação do usuário.
3. Branch `feat/<descricao>`.
4. Implementar (especialista da stack) em passos pequenos.
5. Build + testes; para app, rodar no simulador e conferir a tela.
6. `revisor` no diff.
7. Atualizar `CHANGELOG.md`/docs do projeto. Reportar ao usuário; commit/PR só se ele pedir.
